# Competitor map: Logos

Run: 2026-10-03 (first fill, kitchen opening). Sources: the open-source harvest done for Logos on 2026-10-03 (64 repos, each clone read for its LICENSE, stack and files; notes kept outside this repo), plus `gh api repos/<owner>/<repo>` and README reads on 2026-10-03 for Omnara and T3 Code, and WebFetch of the Moshi Herdr guide. Star counts, user counts and engagement are deliberately left out. `?` means no source was read for that cell, not that the feature is missing.

## Product

- Name: Logos (working name; a naming round is running)
- Flagship: a native Android control surface for one operator's agent fleet. It speaks into, reads and moves between many Claude Code, Codex and Grok sessions running in Herdr on the operator's machines, over plain SSH on Tailscale. It is a ConnectBot fork, so the full terminal stays underneath.
- Our surfaces:
  - main (`3c3345d4`): the dictation compose bar (`ui/components/TerminalComposeBar.kt`), the two-row control keys (`TerminalKeyboard.kt`), screenshot paste over SFTP (`transport/SSH.kt` `uploadFile`), ConnectBot's host-key and password prompts (`ui/components/InlinePrompt.kt`)
  - in flight (open PRs): session drawer with attention notifications (#11), mic button and sticky Ctrl (#10), seeded Sun host (#28), Herdr key row and `SSH.exec` (#30), Read button and reader (#31), Tailscale machines list (#32), CI fix (#29)
  - debug build `solutions.ormus.logos.debug`, activity `org.connectbot.ui.MainActivity`, proven on the `vibe_pixel` emulator (`emulator-5554`) against a Herdr host
